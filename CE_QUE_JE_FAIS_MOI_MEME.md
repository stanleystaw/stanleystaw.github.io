# Ce que je fais moi-même (et personne d'autre)

5 actions. Total : ~20 minutes. Tout le reste est déjà fait.

## 1. Google Search Console — 5 min (LE plus important)
1. Va sur **search.google.com/search-console** (connecté avec ton Gmail)
2. « Ajouter une propriété » → colonne de droite **« Préfixe de l'URL »** → colle `https://stanleystaw.github.io/`
3. Google propose une validation par **« Balise HTML »** : copie le code qu'il te donne et **envoie-le-moi ici** → je l'installe dans le site en 1 minute → tu cliques « Valider »
4. Une fois validé : menu **« Sitemaps »** → tape `sitemap.xml` → Envoyer
5. Barre « Inspection de l'URL » en haut → colle l'adresse du site → **« Demander une indexation »**

## 2. LinkedIn — 10 min
1. Ton profil → **« Modifier le profil et l'URL publique »** (en haut à droite) → active **« Visibilité publique de votre profil »** (sans ça, Google et les IA ne te voient pas)
2. Dans la carte du haut (Intro) → crayon → section **« Site web »** → ajoute `https://stanleystaw.github.io/` (type : Portfolio)
3. Section **« Sélection »** (Featured) → **+** → ajoute le même lien
4. Bonus : colle le texte de `ARTICLE_DEVTO.md` en post LinkedIn (sans la partie entre --- du début)

## 3. dev.to — 5 min (pas de nouveau mot de passe)
1. Va sur **dev.to** → **« Continue with GitHub »** (un clic, ça utilise ton compte existant)
2. **« Create Post »** → ouvre `ARTICLE_DEVTO.md` → copie tout le contenu sous la ligne des --- → colle → **Publish**

## 4. YouTube — 2 min
1. Chaîne **HistoireAi-r6p** → Personnaliser → Informations générales → **« Liens »** → ajoute le portfolio
2. À chaque nouvelle vidéo : le lien en première ligne de la description

## 5. Le bouche-à-oreille — 1 min par personne
Envoie le lien à Liam et à tous ceux avec qui tu as travaillé, avec une phrase du genre :
> « J'ai mis mon portfolio en ligne : https://stanleystaw.github.io/ — laisse-moi un avis vérifié dessus si on a bossé ensemble ! »

Chaque lien partagé = un signal pour Google. Et leurs avis rempliront ta section « Avis vérifiés ».
